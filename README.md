# Navigation Graph Visualizer (GraphFlow v2.4 Core)

Dijkstra algorithm pathfinding visualizer service and interactive Google Apps Script web application.

## Directory Structure
- `fasion/server/`: FastAPI backend service with Dijkstra engine & step snapshot / histogram generator
- `gas/`: Google Apps Script web application with interactive Stitch Tailwind UI
- `nevigation_graph/`: Dedicated navigation graph GAS webapp project
- `database/`: PostgreSQL schema and seed data
